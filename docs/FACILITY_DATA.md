# 道の駅 施設属性データ（RVパーク・温泉）

作成日: 2026-09-08 / 対象: `fix/pretest-ux`

## 1. 定義

- **RVパーク**: 日本RV協会（JRVA）が認定した正式な「RVパーク」であること。単なる広い駐車場・
  「車中泊できそう」という推測・非公認の車中泊スポットは含まない。道の駅の敷地内、または
  道の駅自身が運営・案内する併設施設であることを要件とする。同じ市区町村内に別法人が運営する
  RVパークがあるだけでは「道の駅にRVパークあり」とはしない（実データ監査で、車で数分の
  距離にある別施設のケースを複数確認し、いずれも対象外とした）。
- **温泉**: 道の駅施設内、または道の駅と一体運営・徒歩圏の併設温泉。数km離れた周辺温泉は
  含まない。全国「道の駅」連絡会が公式に管理する施設カテゴリ「温泉施設」の判定をそのまま採用する。

## 2. データソースと確認方法

### 温泉
全国「道の駅」連絡会公式サイト（michi-no-eki.jp）は駅ごとに18種類の設備アイコン（ATM/
レストラン/温泉施設/キャンプ場等/EV充電施設等）をon/offで管理しており、「温泉施設」は
そのうちの1つ（内部facility_id=13）。検索フォーム（`/stations/search/{都道府県チェックボックスid}+.../{施設チェックボックスid}/all`）
から東北6県一括・温泉施設のみで絞り込み、該当駅をすべて取得した（2026-09-08確認、21駅、
1ページに収まりページングなし＝取得漏れなし）。全国「道の駅」連絡会は道の駅の公式窓口団体
であり、STEP2の優先情報源「2. 自治体・観光協会等の公的情報」に相当する一次情報として扱う。

### RVパーク
日本RV協会（JRVA）公認RVパークの検索サイト（rv-park.jp、実データは`web.rv-park.jp/search?pref=...`）
から東北6県それぞれの掲載施設（名称・住所）を全件取得した（2026-09-08時点、計45施設）。
各施設の住所を道の駅住所と突き合わせ、以下のいずれかを満たす場合のみ「道の駅併設」と判定した:
- 住所が同一（大字・字・番地まで一致）
- 施設側の説明文で「道の駅併設」等の明記がある

上記2条件を満たしたのは**きらら289**（福島県南会津郡南会津町、施設名も「北日光奥会津・
道の駅きらら289 RVパーク」）の1件のみ。

住所の郡・町名までは一致するが具体的な字・番地が異なる4件（道の駅はしかみ／しちのへ／
青の国ふだい／白鷹ヤナ公園それぞれの近隣に別法人運営のRVパークが存在するケース）は、
個別にWeb検索で実際の位置関係を確認した結果、いずれも車で2〜3分程度離れた別施設と判明し、
対象外と判定した（例: RVパークみちのくはしかみは「道の駅階上まで車で3分」と施設側の
紹介記事に明記）。

## 3. 収録件数（東北6県181駅・182施設、2026-09-08時点）

- RV_PARK_COUNT = 1（きらら289）
- ONSEN_COUNT = 21
- BOTH_COUNT = 1（きらら289はRVパーク・温泉の両方を満たす）
- UNKNOWN_RV_COUNT = 0 / UNKNOWN_ONSEN_COUNT = 0
  （両施設とも東北6県全件を網羅的に照合できたため、該当なしは`unknown`ではなく`no`とした。
  推測ではなく「確認した上での不在」であることに注意）

温泉21駅の内訳（一部）: 浅虫温泉・いかりがせき（青森県）／雫石あねっこ・とうわ（岩手県）／
上品の郷・おながわ（宮城県）／やたて峠・象潟・おおゆ（秋田県）／天童温泉・鳥海（山形県）／
喜多の郷・きらら289・尾瀬檜枝岐（福島県）ほか。

## 4. データ形式

`src/types.ts`の`Station.facilities`（`StationFacilities`型）に、駅ごとに以下を保持する:

```ts
facilities?: {
  rvPark: 'yes' | 'no' | 'unknown';
  onsen: 'yes' | 'no' | 'unknown';
  source?: string;      // 主な根拠URL
  lastChecked?: string; // YYYY-MM-DD
}
```

47都道府県への拡張時も同じ型・同じ絞り込みロジック（`src/lib/ui.ts`の`matchesFacilityFilter`/
`filterStations`）をそのまま使える設計にしてある。追加県のデータも同じ2つの情報源
（全国「道の駅」連絡会の温泉施設フラグ、JRVA RVパーク一覧との住所照合）で収集することを想定。

## 5. 今後の運用

- 温泉・RVパークいずれも認定状況は変わり得るため、定期的な再確認が望ましい
  （`lastChecked`で最終確認日を追える設計にしてある）。
- 新規道の駅追加時は、上記2ソースを確認した上で`facilities`を追加する
  （確認できない場合は`'unknown'`のままにし、`'no'`と決めつけない）。
