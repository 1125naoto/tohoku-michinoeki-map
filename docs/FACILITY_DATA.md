## 1. 定義

- **RVパーク**: 日本RV協会（JRVA）が認定した正式な「RVパーク」（上位グレードの「RVパーク」・
  簡易グレードの「RVパークライト」の両方を含む）であること。単なる広い駐車場・
  「車中泊できそう」という推測・非公認の車中泊スポットは含まない。道の駅の敷地内、または
  道の駅自身が運営・案内する併設施設であることを要件とする。
  候補は以下の`relation`（`FacilityRelation`型）で分類し、**onsite・integratedのみ**を
  ユーザー向け「RVパークあり」(`rvPark='yes'`)に含める:
  - `onsite`: 道の駅の駐車場・敷地内にある
  - `integrated`: 道の駅の正式構成施設として運営・案内されている（onsiteを包含する強い分類）
  - `adjacent`: 住所がほぼ同一だが、別法人が運営する隣接別施設（`rvPark='no'`のまま記録のみ）
  - `nearby`: 同一市町村内だが徒歩圏外・車で数分程度の別施設（`rvPark='no'`のまま記録のみ）
  - `unrelated`: 施設自体が道の駅と無関係
- **温泉**: 道の駅施設内、または道の駅と一体運営・徒歩圏の併設温泉。数km離れた周辺温泉は
  含まない。全国「道の駅」連絡会が公式に管理する施設カテゴリ「温泉施設」の判定をそのまま採用する。

## 2. データソースと確認方法

### 温泉
全国「道の駅」連絡会公式サイト（michi-no-eki.jp）は駅ごとに18種類の設備アイコン（ATM/
レストラン/温泉施設/キャンプ場等/EV充電施設等）をon/offで管理しており、「温泉施設」は
そのうちの1つ（内部facility_id=13）。検索フォーム（`/stations/search/{都道府県チェックボックスid}+.../{施設チェックボックスid}/all`）
から東北6県一括・温泉施設のみで絞り込み、該当駅をすべて取得した（2026-09-08確認、21駅、
1ページに収まりページングなし＝取得漏れなし）。全国「道の駅」連絡会は道の駅の公式窓口団体
であり、STEP2の優先情報源「2. 自治体・観光協会等の公的情報」に相当する一次情報として扱う。

### RVパーク
日本RV協会（JRVA）公認RVパークの2つの独立した一覧サイト（rv-park.jpの都道府県別検索、
kurumatabi.comの地方別一覧）から東北6県それぞれの掲載施設（名称・住所）を
**ページネーションを最後まで確認した上で**全件取得した（2026-09-08時点。
rv-park.jp計58施設: 青森9・岩手7・宮城11・秋田2・山形7・福島22。kurumatabi.com計約73施設:
青森10・岩手15・宮城15・秋田6・山形10・福島27。両サイトは重複が多いが完全一致ではない）。
各施設の住所を道の駅住所と突き合わせ、以下のいずれかを満たす場合のみ`relation=onsite`
または`integrated`（＝ユーザー向け「RVパークあり」）と判定した:
- 住所が同一（大字・字・番地まで一致）
- 施設側の説明文で「道の駅併設」等の明記がある

上記条件を満たしたのは4件（いずれも施設名に「道の駅」を含み、住所完全一致、掲載ページに
「道の駅併設」と明記）:
- **きらら289**（福島県南会津郡南会津町）
- **道の駅ならは**（福島県双葉郡楢葉町）
- **道の駅猪苗代**（福島県耶麻郡猪苗代町）
- **三滝堂**（宮城県登米市。JRVA認定「RVパークライト」。標準の一覧検索2種類（rv-park.jp、
  kurumatabi.com）のいずれにも出現せず、専用ページ(rv-park.jp/map/151)・道の駅公式サイト
  (mitakido.jp/rv-park/)・宮城県観光連盟公式ページ（「コンビニ、ドッグラン、RVパーク併設!!」
  と明記）で発見・確認した。詳細はセクション9参照）

`relation=adjacent`（隣接別施設、ユーザー向けには含めない）と判定した1件:
- **寒河江（チェリーランド）**: RVパーク「CLAAPIN SAGAE」が道の駅とほぼ同一住所
  （919-6 / 道の駅は919-8）にあるが、実際は隣接する屋内型児童遊戯施設
  「クラッピンサガエ」に併設された別法人運営施設。Web検索で「施設の隣には道の駅
  チェリーランドがあります」と確認（2026-09-08）。道の駅自体の運営ではないため
  `rvPark='no'`とするが、住所が極めて近いため`relation`で明示的に記録する。

`relation=nearby`（同一市町村内だが徒歩圏外、ユーザー向けには含めない）と判定した4件
（住所の郡・町名までは一致するが具体的な字・番地が異なるケース）:
道の駅はしかみ／しちのへ／青の国ふだい／白鷹ヤナ公園。個別にWeb検索で実際の位置関係を
確認した結果、いずれも車で2〜3分程度離れた別施設と判明した（例: RVパークみちのくはしかみは
「道の駅階上まで車で3分」と施設側の紹介記事に明記）。

過去にRVパークを併設していたが現在は終了している駅も確認した:
- **たかはた**（山形県東置賜郡高畠町）: 旧「RVパーク道の駅たかはた」。高畠町公式サイトで
  利用休止が発表され、くるま旅公式サイトでも「【提携終了】」と明記されている
  （2026-09-08 Web検索確認）。過去記事のみを根拠にyesとせず、現行のrv-park.jp/kurumatabi.com
  登録一覧に存在しないことも確認した上でrvPark='no'とした（町内の「RVパーク高畠ふれあい市」
  は異なる大字にある無関係の別施設）。

## 4. データ形式

`src/types.ts`の`Station.facilities`（`StationFacilities`型）に、駅ごとに以下を保持する:

```ts
facilities?: {
  rvPark: 'yes' | 'no' | 'unknown';
  onsen: 'yes' | 'no' | 'unknown';
  rvParkRelation?: 'onsite' | 'integrated' | 'adjacent' | 'nearby' | 'unrelated';
  source?: string;      // 主な根拠URL
  lastChecked?: string; // YYYY-MM-DD
}
```

47都道府県への拡張時も同じ型・同じ絞り込みロジック（`src/lib/ui.ts`の`matchesFacilityFilter`/
`filterStations`）をそのまま使える設計にしてある。追加県のデータも同じ2つの情報源
（全国「道の駅」連絡会の温泉施設フラグ、JRVA RVパーク一覧との住所照合）で収集することを想定。

## 5. 初回監査の誤り（2026-09-08 再監査で判明・修正済み）

初回監査（本ドキュメント初版）ではRV_PARK_COUNT=1（きらら289のみ）と報告したが、
**ならは・猪苗代の2件を取りこぼしていた**。

**ROOT_CAUSE**: rv-park.jp検索結果は1ページ10件で、11件以上ある都道府県は
`&page=2`等のページネーションが必要だった。初回監査ではこのページネーションを確認せず
1ページ目のみ取得していた。青森(9件)・岩手(7件)・秋田(2件)・山形(7件)は
たまたま10件以内で1ページに収まっていたため実害が無かったが、福島県は実際には22件あり
（初回取得は10件のみ）、2ページ目・3ページ目に「RVパーク 道の駅ならは」
「RVパーク道の駅猪苗代」が掲載されていたため、これらを見落とした。

再監査では都道府県ごとに検索結果の総件数表示（例:「10／22件」）を必ず確認し、
2ページ目以降が存在する場合は最後のページまで取得することで解消した。

## 6. 第3回監査の誤り（2026-09-08 三滝堂を追加で取りこぼしていた）

第2回監査でRV_PARK_COUNT=3（きらら289・ならは・猪苗代）と報告したが、ユーザー指摘により
**道の駅三滝堂（宮城県登米市）**の1件をさらに取りこぼしていたことが判明した。

**ROOT_CAUSE**: 三滝堂のRVパークはJRVA認定「**RVパークライト**」（通常の「RVパーク」より
簡易な認定条件のグレード）であり、rv-park.jpの標準的な都道府県別検索(`/search?pref=`)にも、
kurumatabi.comの地方別一覧(`/park/{都道府県}/`)にも一切出現しない。専用ページ
(`rv-park.jp/map/151`)や道の駅公式サイト内の専用ページ、自治体系観光サイト（宮城県観光連盟）
でのみ確認できた。第三情報源として使った「道の駅完全ガイド」の全国39か所一覧記事も、
この施設は掲載していなかった（同記事も恐らく「RVパーク」グレードのみを対象にしている）。

このため、**「複数の一覧サイト・第三情報源と突き合わせて一致した」ことをもって
「取りこぼしなし」の証明にはできない**と判断した（ユーザー指摘のとおり）。
一覧サイト2種類・第三情報源1種類のいずれもが同じ抜け（三滝堂）を共有していたため、
相互確認では検出できなかった。今後同様の抜けが皆無であるとは断言できないため、
`UNKNOWN_RV_COUNT=0`は「現時点の最善の結果」であり「絶対的な悉皆性の証明」ではないことを
明記する。

再監査では、一覧サイトを2種類（rv-park.jp・kurumatabi.com）に増やしてクロスチェックし、
「RVパークライト」というグレード名そのもので追加のWeb検索を行い、既知の一覧に出現しない
候補（三滝堂）を個別に発見・検証した。また、住所がほぼ同一だが実際は隣接する別法人施設
（寒河江のCLAAPIN SAGAE）についても`relation=adjacent`として明示的に記録し、
「yes/noに単純に丸めず根拠を残す」設計（`rvParkRelation`）に変更した。

## 7. 機械可読データ（監査証跡）

`data/facility-audit.json`に、東北6県182施設すべてについて
`{ stationId, stationName, prefecture, rvPark: {status, relation, source, checkedAt, evidence}, onsen: {...} }`
の形式で監査証跡を記録している。将来47都道府県へ拡張する際も同じ監査フローで生成できる構造。

## 8. 今後の運用

- 温泉・RVパークいずれも認定状況は変わり得るため、定期的な再確認が望ましい
  （`lastChecked`で最終確認日を追える設計にしてある）。
- 新規道の駅追加時は、上記ソースを確認した上で`facilities`を追加する
  （確認できない場合は`'unknown'`のままにし、`'no'`と決めつけない）。
- RVパークは「RVパークライト」等のグレード違いで一覧サイトの索引から漏れることが
  実証されている（セクション6）。今後の再確認では、都道府県別の標準検索だけでなく
  「RVパークライト [都道府県名]」等のグレード名を含めた個別検索も行うこと。
  一覧サイトとの一致だけを根拠に「取りこぼしなし」と判定しない。
