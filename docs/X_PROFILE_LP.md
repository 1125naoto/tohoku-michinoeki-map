# Xプロフィール用LP（/lp/）

Xのプロフィール（Webサイト欄）から誘導する、明るい画像中心の縦長・販売LP。既存の公式トップ（`/`）と販売ページ（`/monitor/`）は上書きしない。

- 実装: `src/officialSite/lp.ts`（公式サイトのビルドが `lp/index.html` を追加で出力する）
- 画像: `public/official/lp/lp-01〜10.webp`（941w）と `-480.webp`（480w）。元は Owner 提供の `道ナビLP1〜10.png`（計22MB → 2.5MB）
- テスト: `src/officialSite/lp.test.ts`（単体）／`scripts/lp-qa.mjs`（実ブラウザでスマホ・PC・リンク・速度）
- 状態: **未公開**（公式ドメインへのデプロイは Owner 承認待ち）

## 公開URL案（Xプロフィールのサイト欄用）

```
https://michinoekinavi.jp/lp/?utm_source=x&utm_medium=profile&utm_campaign=lp1
```

購入記録の Client reference ID は `x_profile_lp1` になる（`utm_*` が無いときは既定の `lp1`）。LP は常に noindex（検索には出さず、Xからの流入専用）。

## 公開手順（Owner 承認後）

```
npx vite-node scripts/build-official.ts        # dist-official/ を作る（lp/ を含む）
powershell -File scripts/deploy-official.ps1   # 公式サイトのリポジトリへ通常 push（force push しない）
```

## 画像と現行アプリの照合（Owner の確認が必要）

画像は機能紹介用のイメージ（生成画像）で、アプリの実画面ではない。照合の結果:

| 画像 | 画像の表示 | 現行アプリ | 対応 |
|---|---|---|---|
| 1 | 「月額250円（税込）」だけ | 2026-10-01 決定の料金は「最初の2か月 250円/月→3か月目以降 500円/月」＋年間 4,980円。旧・250円固定のリンクは新規販売に使わない | **HTMLの丸で覆い、実際の料金を表示**。購入欄で全料金と自動更新を明示 |
| 1, 3 | 全国1,237施設 | `STATIONS.length` = 1,237 | 一致（テストで固定。件数が変わったら画像の作り直しが必要） |
| 6, 10 | 道の駅詳細の「クチコミ」タブ | 口コミ・評価はアプリ内に表示しない（Googleマップへのリンク） | 購入欄に「口コミ・評価はアプリ内には表示しない」を明記。**画像の差し替えを推奨** |
| 6, 10 | 周辺スポットに「買い物」カテゴリ・「地元産直市場」 | 周辺スポットのカテゴリは 食べる・観光・温泉・宿泊 | 購入欄に「画像はイメージ」を明記。**画像の差し替えを推奨** |
| 7, 9 | アプリ内のターンバイターン案内画面（「道の駅まで1.2km」） | アプリ内に案内機能は無い（Googleマップで開く） | 同上。**画像の差し替えを推奨** |
| 1〜4, 8 | 下部タブ「地図・一覧・行きたい・設定」、「地図で探す／一覧で探す／エリアで探す」の切替 | コード上のタブは `map` / `route` / `records` の3つ（`src/App.tsx` の `type Tab`）。その名前の切替は無い | 同上。**画像の差し替えを推奨** |
| 5 | 「最適な順番でルート化」 | 経路の順序最適化（2-opt）はある。「最適」は近似 | 許容（文言は画像のまま） |
| 9 | 「東北の美しい景色を〜」 | 全国版の販売ページ | 軽微。差し替え時に直すと良い |
| 2〜9 | 「次のページで〜」の焼き込みボタン | — | 画像の上に実リンクを重ねた（ラベルと遷移先が合わない箇所あり。下記） |

画像の「次のページで〜」ボタンの文言と、番号順で次に来る画像が一致しない箇所: 画像6（実際の周辺スポット画面）、画像7（便利な設定や使い方）、画像9（ルート作成の詳しい使い方）。順番どおり（1→10）に並べたため。並びを変えるか、ボタンの文言を作り直すと良い。

画像10の焼き込みボタン（行き先が無い）は、画像の下端を切り落として外した。
