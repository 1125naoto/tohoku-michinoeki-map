# 東北・道の駅制覇マップ

東北6県（青森・岩手・宮城・秋田・山形・福島）の**全道の駅**を地図上で管理し、
訪問記録・スタンプ取得・県別達成率・営業時間表示・週末の周遊ルート提案までできるWebアプリ（PWA）です。

- APIキー不要・無料で動作（地図は OpenStreetMap、経路計算は OSRM 公開デモサーバー）
- スマートフォン優先UI・全画面地図モード対応
- 訪問記録・保存ルートはお使いの端末内（localStorage）にのみ保存（サーバー送信なし）
- ホーム画面に追加してアプリのように使えるPWA（オフラインでも一覧・記録の閲覧/更新が可能）

## 起動方法（Windows・ローカルで使う場合）

1. **`start-michinoeki-map.bat` をダブルクリック**するだけです。
   - 初回は自動でセットアップ（依存関係のインストール＋ビルド）が走ります。数分かかります。
   - 起動確認後、ブラウザで `http://127.0.0.1:4173` が自動で開きます。
2. **停止方法**: 黒いウィンドウで `Ctrl+C` を押す（または黒いウィンドウを閉じる）。
3. **再起動方法**: もう一度 `start-michinoeki-map.bat` をダブルクリック。2回目以降はすぐ起動します。
4. 同じWi-Fi内の他の端末からは `http://<このPCのLAN IP>:4173` でもアクセスできます
   （起動時にコンソールへ表示されるアドレスを使ってください）。

※ 事前に [Node.js (LTS版)](https://nodejs.org/ja) のインストールが必要です。

- **道の駅「石川」**（福島県石川郡石川町・第64回登録・令和8年度オープン予定）は

4. **Wikidata**（読み仮名・公式サイトURLの補完。座標は公式ポータルと突合し2km以上の乖離ゼロを確認）
5. **国土地理院 住所検索API**（開業前施設の座標付与）

### データの設計と更新方法

- マスターデータは `src/data/stations.json` に**ユーザーの訪問記録と完全分離**して保存しています。
- 各駅は永続ID（例: `mne-18900`）を持ち、訪問記録はIDのみを参照するため、
  **駅データを更新しても既存の訪問記録は失われません**。
- 更新するには `src/data/stations.json` を編集（または再生成）して `npm run build` を実行します。
  追加時は `id / name / pref / city / address / lat / lng / status / infoUrl / verifiedAt / sources` が必須です。
- データの整合性は `npm test` の**データテスト**（ID重複・座標範囲・県別件数照合など）で自動検証されます。

### 営業時間・休館日について

- 営業時間データは `src/data/hours.json` に182施設分収録しています（情報源: 全国「道の駅」連絡会）。
- 確証が持てない駅・情報が見つからない駅は**推測せず「要確認」表示**にしています
  （営業時間を勝手に埋めることはしていません）。
- 表示ステータス: 営業中 / まもなく終了（閉店60分前〜） / 営業時間外 / 開業前 / 要確認。
  時刻はブラウザの設定に関わらず**日本時間（Asia/Tokyo）固定**で判定します。
- 冬季閉鎖が確認されている駅（わきのさわ・かわうち湖・しんごう・みんまや・こどまり・こさか七滝）には注記を表示しています。
- 営業時間は変わりやすいため、出発前に必ず詳細カードの「公式情報を見る」から最新情報を確認してください。

## 地図の表示設定

- 初期状態では東北6県**全182施設を個別のアイコンで表示**します（広域ではまとめ表示に切替も可能）。
- ズームに応じてアイコンサイズ・駅名ラベルの表示量が自動で変わります（タップ領域は常に約44×44px確保）。
- 「まとめて表示（クラスター）」「駅名表示（自動/常に表示/非表示）」は地図の凡例パネルから切り替えでき、
  設定は端末に保存され次回起動時も維持されます。

## 記録のバックアップ・復元

- 訪問記録・スタンプ・保存ルート・地図設定は「保存」タブの「記録をバックアップ」からJSONファイルに書き出せます。
- 機種変更・別ブラウザへの移行時は、同じ画面の「バックアップを復元」からファイルを選択してください。
  「統合」（既存記録を残しつつ合わせる）と「上書き」（すべて置き換える）を選べます。
- バックアップの中身が壊れている・形式が不正な場合は復元前にエラー表示し、既存の記録は変更しません。

## 訪問記録の保存場所

- 訪問状態・スタンプ・保存ルート・地図設定はすべて**ブラウザの localStorage** に保存されます。
  - `tohoku-me:visits:v2` … 訪問・スタンプ記録（旧 `v1` からは初回起動時に自動移行）
  - `tohoku-me:routes:v1` … 保存ルート
  - `tohoku-me:trip:v1` … 旅行中の進行状態
  - `tohoku-me:map-settings:v1` … 地図の表示設定
- サーバーには何も送信されません。ブラウザのサイトデータを消すと記録も消えます（事前にバックアップ推奨）。
- 「保存」タブの「すべての記録を初期化する」から（確認画面つきで）リセットできます。

## ルート提案の仕組み

- **使用可能時間 = 移動時間 + 各駅の滞在時間 + （帰着ありの場合）帰路 + 安全マージン** をすべて含めて計算します。
- 経路・所要時間は可能な場合 **OSRM（キー不要の公開デモサーバー）による実道路ベースの推定**を使用します。
  応答が得られない場合のみ、直線距離×1.35の道路補正・一般道40km/h・高速60km/h想定・区間ごとに5分のバッファ・
  冬季（11〜3月）2割増しの**概算**にフォールバックします。どちらを使ったかは画面上に明記されます
  （渋滞・通行止め等のリアルタイム情報は反映されません）。
- 3種類のコース（がっつり周遊/バランス/ゆったり）を安全マージン付きで提案し、それぞれ提案理由を表示します。
- 開業前・休止中の駅は候補から除外。時間制限を超えるルートは提案しません。
- 各駅から次の駅への移動は「Googleマップでナビ開始」から確認・利用できます
  （経由地が多い場合はGoogleマップの上限に合わせて区間分割されます）。

## PWA・オフライン動作

- ホーム画面に追加すると全画面アプリとして動作します（Web App Manifest + Service Worker）。
- オフラインでも: 道の駅一覧・訪問記録の閲覧/更新・保存ルートの閲覧が可能です。
- オフラインでは利用できないもの: 地図タイルの新規読み込み・公式ページ・Googleマップ・住所検索・経路計算
  （画面上部にオフライン表示が出ます）。
- キャッシュは新しいビルドを検知すると自動更新されるため、古い道の駅データが残り続けることはありません。
