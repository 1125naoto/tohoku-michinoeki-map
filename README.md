# 東北・道の駅制覇マップ

東北6県（青森・岩手・宮城・秋田・山形・福島）の**全道の駅**を地図上で管理し、
訪問記録・スタンプ取得・県別達成率・週末の周遊ルート提案までできるWebアプリ（PWA）です。

- APIキー不要・無料で動作（地図は OpenStreetMap）
- スマートフォン優先UI・ダークモード対応
- 訪問記録はお使いの端末内（localStorage）にのみ保存
- ホーム画面に追加してアプリのように使えるPWA

---

## 起動方法（Windows・初心者向け）

1. **`start-michinoeki-map.bat` をダブルクリック**するだけです。
   - 初回は自動でセットアップ（依存関係のインストール＋ビルド）が走ります。数分かかります。
   - 完了するとブラウザで `http://localhost:4173` が開きます。
2. **停止方法**: 黒いウィンドウで `Ctrl+C` を押す（または黒いウィンドウを閉じる）。
3. **再起動方法**: もう一度 `start-michinoeki-map.bat` をダブルクリック。2回目以降はすぐ起動します。

※ 事前に [Node.js (LTS版)](https://nodejs.org/ja) のインストールが必要です。

### データの設計と更新方法

- マスターデータは `src/data/stations.json` に**ユーザーの訪問記録と完全分離**して保存しています。
- 各駅は永続ID（例: `mne-18900`）を持ち、訪問記録はIDのみを参照するため、
  **駅データを更新しても既存の訪問記録は失われません**。
- 更新するには `src/data/stations.json` を編集（または再生成）して `npm run build` を実行します。
  追加時は `id / name / pref / city / address / lat / lng / status / infoUrl / verifiedAt / sources` が必須です。
- データの整合性は `npm test` の**データテスト**（ID重複・座標範囲・県別件数照合など14項目）で自動検証されます。

### 営業時間・休館日について

営業時間・定休日・冬季閉鎖期間は変わりやすいため、**本アプリには収録していません**。
各駅の詳細カードの「公式情報を見る」から必ず最新情報を確認してください。
冬季閉鎖が確認されている駅（わきのさわ・かわうち湖・しんごう・みんまや・こどまり・こさか七滝）には注記を表示しています。

## 訪問記録の保存場所

- 訪問状態・スタンプ・保存ルートはすべて**ブラウザの localStorage** に保存されます。
  - `tohoku-me:visits:v1` … 訪問・スタンプ記録
  - `tohoku-me:routes:v1` … 保存ルート
  - `tohoku-me:trip:v1` … 旅行中の進行状態
- サーバーには何も送信されません。ブラウザのサイトデータを消すと記録も消えます。
- 「記録」タブの「すべての記録を初期化する」から（確認画面つきで）リセットできます。

## ルート提案の仕組み

- **使用可能時間 = 移動時間 + 各駅の滞在時間 + （帰着ありの場合）帰路** をすべて含めて計算します。
- 距離・時間は**概算**です: 直線距離×1.35の道路補正、一般道40km/h・高速60km/h想定、
  区間ごとに5分のバッファ、冬季（11〜3月）は2割増し。
- アルゴリズム: 候補絞り込み → 貪欲挿入法（時間予算内・「行きたい」重み付き）→ 2-opt改善。
- 開業前・休止中の駅は候補から除外。時間制限を超えるルートは提案しません。
- 外部のルーティングAPIは使用しないため、**オフラインでもルート計算が可能**です。
- 正確な経路・所要時間は「Googleマップでルートを開く」から確認してください
  （経由地が多い場合はGoogleマップの上限に合わせて区間分割されます）。

## PWA・オフライン動作

- ホーム画面に追加すると全画面アプリとして動作します（Web App Manifest + Service Worker）。
- オフラインでも: 道の駅一覧・訪問記録の閲覧/更新・保存ルートの閲覧が可能です。
- オフラインでは利用できないもの: 地図タイルの新規読み込み・公式ページ・Googleマップ・住所検索
  （画面上部にオフライン表示が出ます）。
- キャッシュは新しいビルドを検知すると自動更新されるため、古い道の駅データが残り続けることはありません。

## 技術構成

React 18 + TypeScript + Vite / Leaflet + OpenStreetMap + leaflet.markercluster /
vite-plugin-pwa (Workbox) / Vitest / Playwright。地図・ルート計算ともにAPIキー・課金は不要です。
